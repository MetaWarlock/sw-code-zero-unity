Вход уровня: $50 = $09 и «отпускание» игрока

Замеры reference/gold_w00…gold_w06 (ram_frames.bin, 2048 Б/кадр). Все 7 миссий одинаково: $50=$09 виден с f328, первый тик диспетчера — f345 (= f328+17), первый сдвиг $0510 — f347.

1. Пауза даёт не счётчик, а незавершённый $DD57

Хвост загрузчика, flat_bank7.txt:3695-3698: DDFE STA $50(=$09) → DE00 JSR $C158 → DE03 JSR $FF06 (1 кадр = f328) → DE06 JMP $C254 → fade-in $C270 (строки 300-351):

C254 LDA #$05 / JSR $FF55 ; C259 JSR $8000 (банк-5 тик) ; C25C JMP $C270
C270 LDA #$30 -> $0F        ; старт fade-in
C272 LDX #$F0 -> $0D        ; шаг -$10 за раунд
C281/C283 LDY #$04 / STY $0E; 4 yield-кадра на раунд (цикл C2A4..C2AE, JSR $FF06)
C2B0 $0F += $0D ; C2B7 CMP #$50 BEQ exit ; C2BD BPL next ; C2BF RTS

Раунды $0F: 30(f329-332) → 20(333-336) → 10(337-340) → 00(341-344) → $F0 (отриццательное) = выход на f345. 1 yield + 4×4 = 17 кадров, всё это время $DD57 не возвращает управление, поэтому CB41/анимация не выполняются (f329-344: $0530/$0540 = 0, $0430 залип на 01).

ПРАВИЛО: после STA $50 = #$09 — 17 кадров заморозки (1 yield + fade-in $C270, затемнять палитру по C292-C2A0); на 18-м кадре (f328+17) обычный per-frame цикл с диспетчером CB41.

2. Обработчик $09 = падение

CB4D LDA $50 / AND #$1F / TAY / CB52 LDA $CB5F,Y / CB57 LDA $CB75,Y / JMP ($00); индекс 9 → $D517 (raw $CB68=$17, $CB7E=$D5). Строки 2630-2646: D517 LDA $04D0 / AND #$0F / D51C BNE $D53F (сид $04D0=$80 → ветка 0); D51E LDA $0560 / CMP #$FA / BCS $D539; D539 JSR $F5A4 / D53C JMP $F5DA; D525 LDA #$06 / LDY #$02 / JSR $F4D7 (= F5A4+F5DA+EB52 пробник тайлов).

F5A4 (7423): $0460 -= $0550 ; $0510 -= $0560 (SEC/SBC, borrow от sub-pixel шага);
             CMP #$F0 / BCC выход, иначе $0510 += $0F, $0520 += carry
F5DA (7444): $0550:0560 -= #$0099  ($99 = $40 во всех 7 захватах)
             CMP #$F9 / BCS ok, иначе $0560 = $F8, $0550 = $00 (терминальная скорость)
F5FC (7459): $0550 = $AB, $0560 = $FF ; посев падения, вызов с DDF9

Численно (w00): f344 vel FFAB → f345 $0460=55,Y=06,FF6B → f346 EA,06,FF2B → f347 BF,07,FEEB → f348 D4,08,FEAB — бит в бит. Пробник EB52 активен только при $0560 < $FA (w00: f368-372), т.е. первые ~22 кадра падения коллизий нет.

3. Вторичные поля

  • f345: $0460 00→55, vel AB FF→6B FF, $0530/$0540=80/01 (пишут CB43/CB4A, НЕ физика), $97 24→04, $3E +1/кадр.
  • f347: $0510 06→07. f348: $0410 00→01, $0430 04→00 (период 5).
  • Посадка: w00 f373 ($0510=$74), w01-04 f381 ($B4), w05-06 f377 ($94); в тот же кадр $04D0→$81, next кадр $0420→$2B (bank2 $9600: LDA #$2B / JSR $FA78), vel пересевается в $FFAB ($F607). $50 остаётся $09: $9600 крутит JMP $9605 до $0410==$11 и не доходит до D556 STA $50=#$00.
  • НЕ условия (константы в окне f328-370): $51=$3C, $3B=0, $65=0, $20=1, $6D=0, $9D=0, $5A=0; $F0 — глубина render-disable (C14E/C158, 1→0 на f328); $92 — глобальный счётчик кадров (C0A1).

4. Уверенность

Механизм паузы и физика f345-f348 подтверждены побайтово по 7 миссиям. Остатки: источник world-specific $0520 (w00/01=$03, w03=$0B, остальные $00; не таблица $DF80) и высота посадки (геометрия vs константа); D525/EB52 как детектор пола выведен из совпадения кадра с $04D0+1, без трассы.

СТАТУС (смена 8, 2026-10-15): перенесено в порт и проверено PhysCompare.WorldWalks — сид теперь f328 + EntryFreezeFrames=16 (17-й кадр приходится на сам сид, т.к. Правило терминальной скорости — побайтовое ($80…$F8 → $F8:$00), а не «16-бит < −$0800»; одиночное касание $10==1 при $0560 >= $FC пола не даёт ($F4E4-$F4F6). Дальше по кадрам стоит $9600 (банк 2, intro-карточка) = G29.
