== Шаг 2: эталон снят ==
python Tools/DarkwingResearch/probe_run.py --out Research/DarkwingDuck/reference/tmp_boss_pilot1 \
  --frames 600 --load-state Research/DarkwingDuck/reference/m1_standing.mss \
  --patch 005B=02 --patch 006D=02 --timeout 300
Маршрут: дверь чекпойнта id $02 ⇒ арена Quackerjack ($31=00, клетка $20). Id дверей семи миссий:
$02/$04/$06/$08/$0A/$0C/$0E.
Таймлайн по ram_frames.bin: f17→f18 $22 33→20; f27 слот 15 $0420=$50 (ядро) и слот 14 $51 (шар);
f28 $50=#$12 + $04D0 81→80 + $0420 01→2C; f29 $3B=#$78; дети $52 с ~f300.
Корректная точка сида = f29 (на f28 ROM ещё должен запись $50=#$12 и активацию слота 15).

== Приёмка (замер, НЕ проход) ==
unity command run_script --file AgentScripts/PhysCompare.cs --entry PhysCompare.BossFightSeed \
  --args '[29]' --project-path "D:/Art/SW Code Zero Unity"
Артефакт: Temp/boss_pilot1_qjack_trace.txt (600 кадров; ниже — строка итоговых расхождений)
  сид f29: ENEMIES MATCH 15/570, первый плохой f45 слот 0E поле state порт $80 против ROM $81
  сид f29: RESULT первый плохой f30 (игрок Y $0107 против $0106, $50 порт $00 против ROM $12)

  без сида $3B/$EE/$ED в AgentScripts/PhysCompare.cs расхождение начиналось с f29 (порт двигал
  замороженный ROM-шар) — три глобала фреймворка боссов теперь сидируются.

FIELDS[X:f100 0F2F!=0F30 Y:f30 0107!=0106 $50 state:f30 0000!=0012 $FB row:f406 0003!=0001 \
$22 cell:f406 0033!=0020 $23 next:f406 0033!=0021 $25 streamcursor:f406 0007!=0008 \
$0460 Yfrac:f30 0008!=00B3 $0470 Xfrac:f100 0080!=0000 $0560 YvelI:f32 00FE!=00FF $0550 YvelF:f30 006B!=00AB]

Граница доказательства: $22/$23/$25 расходятся с f406 — порт, сидированный в середине боя, не
проходит дверь загрузки заново и позже сам возвращается в клетку $33. Это отдельный эффект (не
физика босса), и он зафиксирован, а не скрыт сменой окна.

== Новые гэпы из этого замера ==
G78: ROM держит $50=#$12 неподвижно f28…~f54 (27 кадров, Y/$0460/vy заморожены), хотя $D517 —
one-shot ($D53F CMP #$12 / $D543 BEQ $D568 → $D56F STA $50=#$00; далее $D580 LDA $3B /
$LDA #$0F / $D586 STA $50). Значит при $3B != 0 диспетчер состояний игрока к $D517 не обращается —
гейт ВЫШЕ $D517 (кандидаты: обход $CAFC/$C9AC, либо $F869, который боссы зовут именно в эти кадры).
G78.1: $3B убывает 75 раз за 91 кадр (f29 $78 → f120 $2D), а в порту убывание одно на слот босса
за кадр (EnemyBehaviors.cs:3572…3575).
Не закрыто: победа босса. В tmp_boss_pilot1 Quackerjack-ядро ни разу не зовёт $B39E ($EE не
двигается). Поражение измерено в reference/tmp_boss_pilot14_wolf_defeat: f38 $EE 0F→10, f39 слот 14
$54→$4F, f79 слот умирает, $50 $0F→$15, f355 $31 01→08, f373 новая секция.
