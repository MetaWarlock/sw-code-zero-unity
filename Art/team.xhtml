Выбор исполнителя

Codex координирует работу, принимает и объединяет результаты, выполняет полезные ограниченные задачи; Codex как собственный исполнитель не запускается. В постановке учитывать индекс, сложность и объём работы, требуемую независимость проверки и текущий остаток лимита. Большие самостоятельные задания можно отдавать Kimi; наиболее сложные исследования и проверки — Claude. Для Qoder готовить конкретные входы, границы и проверяемый результат. Оценивать результат по доказательствам и приёмке.

Указанные лимиты описывают условия планирования. Текущий остаток проверяется через API соответствующего исполнителя; если API недоступен, фиксируется UNKNOWN. Процент одного harness не переносится на другой. Правило остановки при остатке менее20% и запрет автоматического использования reset credits установлены в правилах проекта.

Ответственность и изоляция

  • Перед выдачей задачи в Beholder указать исполнителя, разрешённые файлы и области, входы, критерии приёмки и границы ответственности. Собственную учётную запись каждый harness подтверждает своим MCP.
  • Для параллельных изменений при необходимости выделять отдельные Git-ветки, worktree и папки. Перед назначением обновлять рабочую ветку до актуального локального main, сохраняя чужие изменения и уникальную историю.
  • Разделять Editor, сборки, временные результаты и изменяемые тестовые стенды. Пробы, которые временно меняют runtime или общий build output, выполнять последовательно в пределах одного рабочего дерева.
  • Не поручать двум исполнителям одновременную запись в одни файлы или управление одним Editor. Совместимые независимые работы выполнять параллельно; общие изменения объединяет оркестратор после приёмки.
  • Исполнители не запускают другие harness без отдельного разрешения. Оркестратор ждёт итогового результата через acpx и проверяет завершённую работу; полезная независимая работа в это время разрешена.

Текущие назначения, приоритеты, blockers и результаты ведутся только в Beholder ZERO. Этот документ хранит состав и правила распределения работы.
