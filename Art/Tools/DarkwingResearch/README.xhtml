Каталог исследовательских инструментов

Единая точка входа для всех агентов. Проверено по исходникам 2026-10-27; это каталог возможностей и команд, не заявление о прохождении игры. Правила владения, хранения и резервирования — AGENTS.md, урок о потере Temp — N03.

Перед написанием скрипта

  1. Найти нужную возможность в таблице и поиском по исходникам этого каталога и Art/AgentScripts/. Прочитать текущие параметры/пример; не устанавливать инструмент заново ради нового диалога.
  2. Доработать подходящий entry point: входная запись, диапазон, поля, банк/адрес и выход — параметры, а не копия под новый кадр/смену. Переиспользовать существующий запуск Mesen/Unity.
  3. Если расширение не подходит, сначала записать конкретный пробел и причину в текущем STATUS, затем добавить один канонический инструмент и строку сюда. Узкий source-specific probe допустим, новый универсальный движок не требуется.
  4. До передачи выполнить preservation gate AGENTS: исходники в Git/подготовленном source-коммите, необходимые ignored-данные с проверенным backup, полная команда не зависит от утрачиваемого кода в Temp. Размещение файла под Tools само по себе не означает, что файл сохранён в Git.

Примеры команд

Пути OUT выбирает исполнитель в назначенном worktree. В примерах Art/Temp/check — воспроизводимый промежуточный вывод, не место единственного эталона или окончательной приёмки; до передачи нужные результаты сохраняются по правилам AGENTS.

# Уже существующие human recordings; новую запись не требуется создавать ради примера.
python Art/Tools/DarkwingResearch/stand/stand.py replay Art/Playthroughs/20261019T212535Z --runs 2 --output Art/Temp/check/original
python Art/Tools/DarkwingResearch/stand/stand.py unity Art/Playthroughs/20261019T212535Z --output Art/Temp/check/core
python Art/Tools/DarkwingResearch/stand/stand.py states --original Art/Temp/check/original/replay1/buffers.bin --port Art/Temp/check/core/buffers.bin --start 8
python Art/Tools/DarkwingResearch/stand/stand.py buffers --original Art/Temp/check/original/replay1/buffers.bin --port Art/Temp/check/core/buffers.bin --start 8
python Art/Tools/DarkwingResearch/run_check.py --suite --out Art/Temp/check/suite
python Art/Tools/DarkwingResearch/run_check.py --entry PhysCompare.Mission1Contracts --out Art/Temp/check/contracts
python Art/Tools/DarkwingResearch/build_player.py --out Art/Build/DarkwingDuck/DarkwingDuck.exe --evidence Art/Temp/check/build --development

Это примеры синтаксиса по текущим исходникам, не команды, выполненные при создании каталога, и не ожидаемый PASS города. Перед параллельным запуском проверить владельца Editor и выхода. Существующий пользовательский стенд Art/Build/UserStand/shortcuts обновляется на месте согласно AGENTS; этот каталог не создаёт новый стенд.

ACTIVE: гейты цен диспетчера (ZERO-43)

Два режима того же entry point, оба только читают Core и ничего не пишут в игру:

  • state09 Art/Temp/…/state09_gate.csv — ограниченный гейт цены CAFC state 09 на городском маршруте. Позитив: поллы 1941–1977 обязаны равняться original CA59−CA40−18 из city_phases.csv; вызов измерителя до кадра обязан воспроизвести цену самого кадра; сдвинутый ожидаемый результат обязан быть отвергнут. Негативы: на каждом полле state, активность slot0, младший ниббл $04D0 и бита hook $0400 возмущаются и восстанавливаются до кадра — каждый обязан дать отказ; вызов без владельца $F850 обязан отказать ровно на поллу посадки. exit0 = state09 gate PASS, иначе exit1. Это контракт по сохранённым original-ценам, а не runtime-приёмка и не приёмка миссии.
  • dispatch <frames> Art/Temp/…/dispatch_<route>.csv --session Art/Playthroughs/<session> — популльная колонка poll,ran,state,player,playerWhy для любого из четырёх входов (m1 20261019T050329Z/24261, human 20261022T164819Z/38886, city 20261019T212535Z/29360, m3 20261024T183247Z/73407). Длина входа проверяется, SHA-256 печатается в stdout. Пара «до/после» — это регресс по общим timing-кодам: совпадение ran/state доказывает отсутствие влияния на состояние игры, совпадение уже поддержанных цен — отсутствие изменения прежних цен. Значения state09 вне проверенного окна остаются не подтверждёнными трассой.

ACTIVE: исходная цена CAFC state 09 (ZERO-44)

Назначение: независимая от Core проверка цены диспетчера игрока CAFC в state 09. Инструмент проходит инструкции fixed bank 7 от CAFC до RTS в CA43 по pre-pass original RAM полла и суммирует циклы NMOS 6502: пересечения страниц и взятые ветвления. Прошлые инструменты не подходят: reached_body_aggregate считает native-цену Core, архивный state09_branch.py покрывает только дешёвую ветвь. Это исследовательская сверка, не runtime и не таблица цен по поллам. Доступ вне RAM $0000–$07FF/bank7 $C000–$FFFF или неизвестный opcode даёт UNSUPPORTED; полный эмулятор не строится. Oracle CA59−CA40−18 (при $65<80, $30=0) читается только после прохода для сравнения. Для каждого полла выход дополнительно сравнивает конечные $0510/$0520/$0550/$0560/$04D0 с RAM следующего полла (post_equal).

Входы: ROM (SHA-256 проверяется кодом), reference/cost-harness/data/phases/city_phases.csv, original Art/Playthroughs/20261019T212535Z/replay1/buffers.bin (4384 байта на полл, RAM — первые 2048 байт записи (poll−1)*4384). Выход: строки JSON в stdout и необязательный новый --json (открывается с x, перезапись запрещена). Exit 0 — только при статусах EXACT/NOT_STATE09.

# Из корня назначенного проекта
python -I Art/Tools/DarkwingResearch/cost/state09_source_price.py "Art/Darkwing Duck (USA).nes" Art/Research/DarkwingDuck/reference/cost-harness/data/phases/city_phases.csv Art/Playthroughs/20261019T212535Z/replay1/buffers.bin 1941 1977 --json Art/Temp/ZERO-44/state09_1941_1977.json
python -I Art/Tools/DarkwingResearch/cost/state09_source_price.py --selftest "Art/Darkwing Duck (USA).nes" Art/Playthroughs/20261019T212535Z/replay1/buffers.bin

Проверено (2026-10-29): 1941–1977 — 37/37 EXACT, post_equal 37/37. Selftest 7/7 PASS. Синтетические правки RAM дают вручную посчитанные по листингу дельты: row-wrap F5A4 +17, F5DA BPL −4, clamp +13, занятая очередь F850 −15. Отрицательные контроли: $04D0&0F≠0 даёт UNSUPPORTED, компаратор отвергает oracle+1. Ограничения: варианты selftest не измерены на оригинале; полл 1978+ (карточка D53F, переключение банка) не поддерживается. Результат — в FACTS ZERO-44.
