Отображение путей: Art/Temp/ZERO-41/имя сохранено как source/имя. Элемент Temp не мог остаться элементом пути архива, потому что .gitignore строка 2 игнорирует любой каталог [Tt]emp/ на любой глубине и такие байты не попали бы в Git. Ни одно правило игнорирования не ослаблено и не дополнено; preserve.py не менялся.

Сохранность в Git. core.autocrlf=input нормализует концы строк при коммите, поэтому в каталоге архива лежит .gitattributes с * -text — только отключение eol-конверсии для этих исторических байтов. Проверено: во всех трёх файлах нет ни одного CR (LF-only), blob каждого файла побайтово равен файлу snapshot и хешу из таблицы ниже.

Реальные входы и почему non-runnable. Все три скрипта читают только argv-пути, а сами пути указывали на Art/Temp/ZERO-41/… слота A, которого больше нет. Данные остались только в snapshot и в Git намеренно не коммитятся: два buffers.bin по 28 145 280 байта — это не тот объём, который должен лежать в каноническом историческом архиве исходников, а их идентичность уже зафиксирована manifest snapshot и (для original-окна) в evidence.json. Ожидаемые входы по строкам запуска:

  • state09_branch.py CITY_PHASES_CSV ORIGINAL_BUFFERS FIRST LAST — city_phases.csv (формат poll,cycles,pc, с заголовком), original clock_oracle/buffers.bin или clock_native/buffers.bin как record по 4384 байта на полл (RAM читается по (poll-1)*4384), диапазон поллов. В snapshot рядом лежат производные окна: city_1924_2100.csv, clock_oracle.csv, clock_native.csv.
  • state09_residual.py CITY_CSV CITY_PHASES_CSV — city_full.csv (native-город с колонками poll,hook,head,scroll,spawn,zone,palette,bank6,bank1,tail,player) и city_phases.csv того же окна.
  • xtext.py FILE NEEDLE [CHARS] — любой текстовый дамп: в слоте A применялся к d_0x0AFC.txt, d_0x1510.txt, d_0x34DB.txt, d_f580.txt (bank-7 ассемблерные листинги).

Скрипты не содержат путей к ROM, эмулятору или игре и ничего не пишут; запускать их здесь не требуется и не планировалось. Значимость этих байтов — метод, а не результат: результат в FACTS.
