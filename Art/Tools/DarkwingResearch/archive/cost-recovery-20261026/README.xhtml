Исторические процедуры восстановления cost-harness

Статус: ARCHIVED / HISTORICAL, не активный entry point. Исходники сохранены без изменений из восстановленного Build/CostHarness/scratchpad-20261026; это замороженные варианты исследования, а не закрытие городского блокера. Активный агрегатор и обработчики фаз — cost/, команды — в едином каталоге.

patch_*.py — старые одноразовые преобразования игрового кода, не патчи для повторного запуска. phase_*, check_thr*, edge_fit*, cov*, slots*, slack, thr_verify, ppu_variants и .orig.cs сохраняют ход технических проверок; некоторые требуют утраченные Temp-входы или старую ревизию. Их воспроизводимость сейчас NOT RUN / частично отсутствуют зависимости. Не запускать массово и не создавать новый вариант лишь из-за неработающего исторического пути; сначала читать актуальные инструменты и свидетельства.

Исходные текстовые дампы и единый city_phase.pkl лежат локально в Research/DarkwingDuck/reference/cost-harness/data/; происхождение, хеши, внешние копии и границы восстановления — в evidence.json. Дубликат city.pkl побайтово равен city_phase.pkl; в активных данных используется один файл. Полный исходный восстановленный каталог, включая этот дубликат, сохранён вне проекта, а не удалён.

Правило дальнейшего жизненного цикла: завершённые blocker-specific инструменты архивируются только после доказанного закрытия блокера и проверки зависимостей, с причиной/ревизией/входами/командой проверки в каталоге. Общие востребованные инструменты остаются активными. Архив сохраняется в Git; при возврате задачи используем или дорабатываем этот источник.
