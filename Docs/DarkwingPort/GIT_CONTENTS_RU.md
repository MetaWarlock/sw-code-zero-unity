# Состав Git и локальные файлы

Проверено 2026-10-18. Исключение из Git не означает удаление с диска.

## Оставлять локально

- `Art/Darkwing Duck (USA).nes` и другие `*.nes`. Ожидаемый SHA-256 исходника:
  `1271dce8678ffc261e2c05cc785ae53e29ac1f9ecf6265a4265bed825abb0a00`.
  Для исследовательских инструментов файл нужно положить по указанному пути самостоятельно.
- `Research/DarkwingDuck/extracted/raw/`: исходные PRG/CHR, их банки, заголовок и
  промежуточные nametable-дампы. Проверено, что `header.bin + prg.bin + chr.bin`
  полностью восстанавливают исходный `.nes`; исключить только расширение `.nes` недостаточно.
  Восстановление этих исследовательских файлов из локального ROM:
  `python Tools/DarkwingResearch/extract_rom.py` из корня проекта.
- `home/` внутри записей Mesen и `Tools/DarkwingResearch/runs/inspect-home/`:
  автоматические рабочие каталоги отладчика. В текущих каталогах находятся `.cdl`.
  Отдельные `coverage.cdl` в записях остаются исследовательскими артефактами.
- `Tools/DarkwingResearch/vendor/mesen-agent/mesen-agent-windows-x64.zip`:
  дубликат распакованных `mesen-agent.exe`, `MesenCore.dll` и `LICENSE`.
  Байтовое совпадение файлов из ZIP с локальными файлами проверено.
  Релиз и контрольная сумма архива сохранены в соседних `release.json` и `SHA256SUMS`.
- Корневые `trace.txt`, `m1z_pit*_report.txt`, кэш Python. Результаты, которые нужны
  как доказательство, сохранять отдельно с описанием сценария и происхождения.
- Кэши и результаты Unity (`Library`, `Temp`, `Build`, `Builds`, `Logs`,
  `UserSettings`) уже исключены.

## Сохранять в Git

- `Assets` вместе с `.meta`, `Packages`, `ProjectSettings`, исходники инструментов,
  документы, каталоги объектов и зафиксированные результаты анализа.
- Исходные эталоны Mesen, сценарии, snapshots, данные кадров и отчёты сравнений.
  Имя `tmp_*`, расширение `.bin` или большой размер сами по себе не делают файл
  ненужным: часть записей используется как доказательство и вход проверок.
- Ранние `Tools/DarkwingResearch/runs/` пока сохраняются: на них ссылается
  `Research/DarkwingDuck/docs/game_flow.md`.
- Распакованная согласованная пара Mesen CLI/core и её лицензия пока сохраняются:
  пути используются инструментами и `toolchain-lock.json`. Переносить её на
  внешнюю загрузку следует вместе с воспроизводимым получением нужной версии.
- Экспорты предыдущего диалога пока сохраняются как указанный в handoff источник.
  В дальнейшем их можно заменить самостоятельными проверенными заметками.

## Перед первой публикацией

`.gitignore` и снятие с отслеживания действуют на последующие коммиты.
ROM и его сырые дампы уже находятся в старой истории: обычный push существующей
ветки отправит и их. История в рамках этой проверки не переписывалась.
Перед публикацией нужно отдельно подготовить историю без исключённых файлов
либо согласовать новый репозиторий с чистым первым коммитом; локальные исходные
материалы и текущую историю сохранить как резервную копию.

Сгенерированные игровые ассеты в `Assets` сохраняются; отсутствие `.nes` в
репозитории не означает отсутствия извлечённого из оригинала контента.
