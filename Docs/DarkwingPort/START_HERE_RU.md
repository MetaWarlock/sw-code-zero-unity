# Запуск задания в ZCode

Открыть существующий workspace `D:\Art\SW Code Zero Unity`, выбрать GLM-5.3-Flash и режим исполнения, позволяющий работать с проектом. `/goal` вводится в чат ZCode; это не команда PowerShell. Goal Mode недоступен в Plan Mode согласно [документации ZCode](https://zcode.z.ai/en/docs/goal).

Отправить следующее сообщение:

```text
/goal Полностью перенести оригинальную Darkwing Duck (USA) с NES на Unity в текущем проекте D:\Art\SW Code Zero Unity, сохранив исходные ресурсы и геймплей согласно критериям приёмки. Сначала прочитай AGENTS.md, Docs/DarkwingPort/IMPLEMENTATION_BRIEF_RU.md и Docs/DarkwingPort/RESEARCH_HANDOFF_RU.md. Они задают объём, архитектуру, этапы M0–M8, известные адреса и ограничения подготовительных материалов. Затем самостоятельно выполни установку/настройку только необходимых инструментов, недостающее исследование ROM, полное извлечение ресурсов, реализацию нативной игровой логики на C#, сравнение с оригиналом и сборку Windows x64. Используй Art/Darkwing Duck (USA).nes как неизменяемый эталон. Итог должен включать все семь миссий, всех боссов, секреты и бонусные участки, всю механику игрока, графику и анимации, музыку и SFX, интерфейс, прогресс, смерть/continue, финал и титры. Не заменяй перенос запуском NES-эмулятора внутри Unity. Используй уже подготовленные материалы как старт, но не считай их полным извлечением или доказательством точности. Веди STATUS.md, FACTS.md, GAPS.md и COVERAGE.csv в Research/DarkwingDuck. Продвигайся небольшими проверяемыми этапами, экономь контекст и не повторяй уже выполненные исследования без причины. Не завершай цель на плане, прототипе, первом уровне или успешной компиляции: требуется полноценная standalone-сборка, обычное полное прохождение и доказательства соответствия по IMPLEMENTATION_BRIEF_RU.md. Работай локально; публикация не входит в задачу.
```

Основной документ — `IMPLEMENTATION_BRIEF_RU.md`. Справочник — `RESEARCH_HANDOFF_RU.md`. Постоянные короткие правила для агента находятся в корневом `AGENTS.md`.

Если сессия была прервана, продолжить существующую цель через `/goal resume`. При новой сессии снова указать прочитать документы и актуальный STATUS; не начинать исследование с нуля. Не менять scope на более простой результат ради завершения Goal Mode.

Подготовка задания завершена на уровне документации. Работа по переносу и приёмке поручена исполнителю; автоматический режим сам по себе не гарантирует корректность результата — её устанавливают описанные проверки.
