# MILESTONES — контрольные точки порта Darkwing Duck

Назначение: чинить по одному шагу и сразу отмечать здесь. Файл нужен, чтобы работа
не терялась при обрыве сессии (лимиты/сбой агента). Правила:

- Отмечать строку как `[x]` **только** когда есть воспроизводимое доказательство
  (команда + артефакт + число). Без доказательства — статус `in` или `blocked`.
- Каждый закрытый шаг — коммит в git с сообщением, начинающимся с `MILESTONE:`.
- Перед тем как что-то портировать, свериться с `Research/DarkwingDuck/COVERAGE.csv`
  и `GAPS.md` — не повторять уже закрытое.
- Блок «СЛЕДУЮЩИЙ ШАГ» ниже всегда актуален: это ровно одна конкретная операция.

## СЛЕДУЮЩИЙ ШАГ

Портировать механику крюков/лазания игрока (банк 7 `$DB6D` захват, `$D7F9` висение,
`$DB8F` подъём, флаг колонки из скрипт-байта ячейки). Доказать покадровым золотым
сравнением, затем снять блокировку G14 (контакт с ходоком за пилоном комнаты 0x02).
