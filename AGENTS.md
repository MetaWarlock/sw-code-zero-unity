# SW Code Zero — entry point

Перед любой работой прочитать [полные правила](Art/AGENTS.xhtml). Канонические материалы — Art/, временные — Art/Temp/. Задачи — только Beholder ZERO.

Порядок работы и оркестрация (Beholder ZERO + acpx, обновление рабочих копий, лимиты каждого harness) — раздел [Обязательная организация работы](Art/AGENTS.xhtml#обязательная-организация-работы-решение-пользователя-2026-10-29); acpx — [постановка → блокирующее ожидание → приёмка](Art/AGENTS.xhtml#acpx-wait). После крупной итерации проверить собственный лимит исполнителя; при остатке <20% остановиться до команды пользователя.
