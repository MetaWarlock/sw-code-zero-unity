# FACTS — установленные факты (факт → доказательство → уверенность)

Формат: утверждение → источник/эксперимент → уверенность (подтверждено / высоко вероятно / гипотеза).

## ROM и среда

| Факт | Доказательство | Уверенность |
|---|---|---|
| ROM SHA-256 `1271dce8…bb0a00`, NES 2.0, MMC1, PRG 128K (8 банков), CHR 128K (32 банка), NTSC | Пересчёт хэша 2026-10-11; manifest.json | Подтверждено |
| Векторы NMI `$C000` (bank7 fixed), RESET/IRQ `$FFE0` | manifest.json | Подтверждено |
| Python 3.14.2, mesen-agent v0.1.0 рабочий, Unity CLI + Editor 6000.6.5f1 доступны | Проверка 2026-10-11 | Подтверждено |

## Форматы данных (из CadEditor-конфигурации, структурный разбор)

| Факт | Доказательство | Уверенность |
|---|---|---|
| 7 групп уровней: типы объектов, layout, метатайлы/макротайлы по `set*0x4000`-смещениям | CadEditor DarkwingDuck.cs + структурный roundtrip в manifest.json | Подтверждено (структура; семантика типов — отдельно) |
| Размещения: 5 параллельных массивов (screenX, localX, screenY, localY, type) | CadEditor | Подтверждено (структура) |
| Анимации (199), статические кадры (314: 311 ROM + 3 RAM), координаты (208) — указатели в PRG bank 5, low/high раздельно | manifest.json roundtrip | Подтверждено (структура) |
| 3 RAM-кадра: 31, 156, 251 ($05B0/$05C2/$05E8) — требуют поиска писателей | manifest.json exceptions | Подтверждено (наличие),.writer неизвестен |
| UI-потоки `0x80B1`, `0x83FC`: PPU addr big-endian + count + literal, `0xFF`-терминатор | CadEditor | Подтверждено (структура) |
| APU callback PC-ориентиры bank 3: $80FD/$80EB/$8215/$8218/$821D (после выборки операндов) | Ранний трейс из подготовки | Ориентир, требует подтверждения |

## Уверенность НЕ подтверждена (см. GAPS.md)

- Семантика type nibble метатайлов (0..5 — названия редактора).
- Соответствие наборов CadEditor реальным миссиям и переходам.
- Формат физики/скоростей, RAM-карта, RNG, тайминги кадров.
- Звуковой движок: init/update, таблицы.
