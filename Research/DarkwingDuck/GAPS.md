# GAPS — неизвестное и следующий проверяемый эксперимент

| # | Пробел | Следующий эксперимент | Статус |
|---|---|---|---|
| G1 | Детерминизм эмулятора из одинакового состояния | Два прогона с одинаковыми параметрами из reset → сравнить RAM/PNG/WAV хэши | В работе |
| G2 | RAM-карта игры (игрок, объекты, состояния, камера) | Динамическая трассировка: input-сценарий + snapshot-диффы; поиск писателей ключевых адресов | — |
| G3 | Главный цикл / NMI / порядок обновления / банк-переключения | Дизассемблирование от векторов + trace; найти NMI ($C000) и main loop | — |
| G4 | 3 RAM-кадра спрайтов (31/156/251) — писатели $05B0/$05C2/$05E8 | Breakpoint write на эти адреса в run, трассировка стека вызовов | — |
| G5 | Звуковой движок: init/update, таблицы песен/SFX, каналы | Трасса APU-записей при загрузке уровня; поиск писателей $4000-$4015/$4017 | — |
| G6 | Физика игрока (гравитация, скорости, прыжок) — точные форматы | Управляемый ввод в эмуляторе: диффы позиций по кадрам → восстановить форматы | — |
| G7 | Семантика type nibble метатайлов и поверхностей | Сопоставить с кодом проверки столкновений (после G3) | — |
| G8 | Соответствие 7 наборов CadEditor миссиям меню | Пройти выбор миссии в эмуляторе, сравнить CHR/палитры/геометрию | — |
| G9 | Специальная ссылка `0x98` (0x198) layout финального уровня | Найти код чтения layout, интерпретировать по переходам | — |
| G10 | Полный каталог объектов: поведение всех 100 ID | Покомпонентный реверс процедур поведения | — |
| G11 | RNG (формула, вызовы, seed) | Найти LFSR/счётчик в RAM, подтверждить трассой | — |
| G12 | Палитры runtime (fade, смена по комнатам) | Дамп PPU-палитры в ключевых точках | — |
